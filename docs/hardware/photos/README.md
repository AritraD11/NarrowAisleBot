# NAB Hardware Photos

First physical photos of the actual robot, taken 5 Aug 2026. Kept here so any
future session can see the real hardware instead of only reading specs.

| File | What's in it |
|---|---|
| `nab_chassis_battery_pi_top.jpg` | Top-down view of the rear chassis. SuperMexx 12.8V 30Ah LiFePO4 battery pack, Raspberry Pi with attached LCD status display, a motor, a heatsink, and the base of the telescoping arm mechanism above (yellow/black hazard-taped platform). |
| `nab_chassis_drivers_wheels.jpg` | Closer view through the chassis's clear acrylic side panel — the two rear Rhino 24V gearmotors, a relay board (power sequencing / E-stop, separate from the main motor drivers), the rear mecanum wheel pair, and the red illuminated power switch. |
| `nab_full_side_arm_lab_01.jpg` | Wide side view showing the full telescoping/linear-rail arm assembly (lead screw + white PTFE rod guides, a "Gear Ratio" labeled motor at its base) alongside the main chassis, in the lab. |
| `nab_full_side_arm_lab_02.jpg` | Another full-side angle — arm mechanism, mecanum wheels, hazard-taped chassis edge, battery, in the lab. |

**Correction on driver placement:** the finned heatsink + cooling fan visible in
these photos belongs to the **arm's** motor driver, not the drivetrain. The
main drivetrain motor drivers are mounted inside the aluminum chassis plates,
not externally visible in these shots.

More photos (internal hardware / driver placement) to be added when available.
